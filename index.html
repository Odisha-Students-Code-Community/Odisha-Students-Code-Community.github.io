[PIPELINE // 04]

THE INDUSTRIAL ASSEMBLY CONVEYOR

Never opened a Pull Request before? Follow our 5-station conveyor belt from zero to your first merged code.

01 FORK

FORK & CLONE THE CODEBASE

STATION_01

Fork the target repository on GitHub to your personal account, then clone it to your local development machine.

git clone https://github.com/Odisha-Students-Code-Community/Odisha-Students-Code-Community.github.io.git
02 BRANCH

SPAWN A FEATURE BRANCH

STATION_02

Always build in an isolated topic branch. Never commit directly to the main branch.

git checkout -b feat/my-first-contribution
03 BUILD

CODE, TEST & VERIFY LOCALLY

STATION_03

Write your code according to the project's standards. For this website, run a simple local web server to verify your changes in your browser:

python -m http.server 8000
04 COMMIT

STAGE & PUSH COMMITS

STATION_04

Write clear, descriptive commit messages describing the problem solved.

git add . && git commit -m "feat(nav): add terminal shortcut" && git push origin feat/my-first-contribution
05 SHIP

OPEN PULL REQUEST & GET MERGED

STATION_05

Open a Pull Request on GitHub. Fill out the PR template. Our maintainers review with constructive feedback and merge your code into production!
