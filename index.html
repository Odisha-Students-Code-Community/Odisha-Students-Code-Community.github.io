CONTRIBUTE/04 — PIPELINE

YOUR FIRST CONTRIBUTION PIPELINE

Open-source isn't magic. It's a standard, repeatable 9-step engineering process.

FULL CONTRIBUTION GUIDE →
STEP // 01

PICK PROJECT

Browse our repositories and pick one that interests you.

github.com/Odisha-Students-Code-Community
STEP // 02

FIND AN ISSUE

Look for tags like good first issue or help wanted.

label: "good first issue"
STEP // 03

FORK & CLONE

Fork repo to your account and clone it to your local machine.

git clone https://github.com/YOU/repo.git
STEP // 04

MAKE A BRANCH

Never work directly on main. Create a descriptive branch.

git checkout -b feat/my-improvement
STEP // 05

WRITE CODE

Implement the bug fix or feature according to requirements.

git status && git diff
STEP // 06

TEST LOCALLY

Verify that everything functions and no errors occur.

python -m http.server 8000
STEP // 07

OPEN A PR

Push your branch and open a pull request explaining your change.

git push origin feat/my-improvement
STEP // 08

CODE REVIEW

Peer reviewers discuss your code and suggest any polish.

status: PR Review In Progress
STEP // 09

MERGE & SHIP

Your code gets merged into production! You are now an open-source contributor.

status: MERGED 🎉
