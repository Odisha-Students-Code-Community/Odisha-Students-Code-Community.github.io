THE STATE-WIDE STUDENT ROSTER

Odisha Students Code Community is not a corporate club or a fee-charging coaching brand. It is an open, distributed movement built by students, for students, uniting engineering colleges, polytechnics, and universities across Odisha.

JOIN THE ROSTER VIA BOT ⚡
VALUE_01 ACTION

BUILD

We prioritize code over talk. Writing real software and shipping working tools teaches more than passively watching endless tutorials.

VALUE_02 OPEN SOURCE

CONTRIBUTE

We participate in the global open-source commons. Contributing fixes and features produces tangible proof-of-work visible to anyone in the world.

VALUE_03 COLLABORATION

COLLABORATE

No campus silos. We connect students across OUTR, VSSUT, Ravenshaw, Silicon, polytechnics, and colleges across all 30 districts into a shared team.

VALUE_04 INCLUSIVE

LEARN

Zero elitism. No gatekeeping. Questions are welcomed, whether you are trying to write your first Git commit or architecting a distributed system.

VALUE_05 COMMUNITY

SHARE

We freely pass along hackathon opportunities, open-source programs, internship leads, and technical learnings to help peers succeed.

VALUE_06 PROOF OF WORK

GROW

Turn student projects into public software. Move from theoretical classroom assignments to public codebases with active user feedback.
