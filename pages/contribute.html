[FIELD_MANUAL // 03]

THE WORKSHOP FIELD MANUAL

You do not need years of prior experience, a fancy degree, or a huge portfolio to contribute. Every senior software engineer began with a single pull request. This manual walks you through the entire pipeline.

BROWSE OPEN ISSUES 🎯
SPEC_01 CORE

REPOSITORY (REPO)

The master project container on GitHub containing code, documentation, issue trackers, commit history, and release tags.

SPEC_02 CORE

FORK & BRANCH

Fork makes a personal copy in your account. Branch isolates your changes (e.g. feat/header-fix) so you never disrupt the production main branch.

SPEC_03 DISPATCH

PULL REQUEST (PR)

A formal submission notifying repository maintainers to inspect your branch, review changes, run automated tests, and merge your code into the upstream repository.

[EXECUTION // PIPELINE]

STEP-BY-STEP TERMINAL PIPELINE

Execute these exact commands in your terminal to build, verify, and ship code to OSCC.

01 ISSUE

CLAIM AN ISSUE OR PROPOSE ONE

STATION_01

Visit any OSCC repository on GitHub. Look for labels like good first issue or help wanted. Comment on the issue asking to be assigned before writing code!

02 FORK

FORK THE REPOSITORY ON GITHUB

STATION_02

Click the Fork button at the top right of the target repository to create an independent copy under your personal GitHub profile.

03 CLONE

CLONE YOUR FORK TO LOCAL DISK

STATION_03

Clone your fork to your workstation and navigate into the project directory:

git clone https://github.com/YOUR_GITHUB_USERNAME/Odisha-Students-Code-Community.github.io.git && cd Odisha-Students-Code-Community.github.io
04 UPSTREAM

CONNECT UPSTREAM REMOTE

STATION_04

Keep your local repo synchronized with the main community repository by adding upstream:

git remote add upstream https://github.com/Odisha-Students-Code-Community/Odisha-Students-Code-Community.github.io.git
05 BRANCH

SPAWN A FEATURE BRANCH

STATION_05

Never work directly on main. Create a descriptive feature branch:

git checkout -b feat/add-terminal-shortcut
06 BUILD

CODE & TEST LOCALLY

STATION_06

Make your edits. Start a local server to verify that styling, links, and console outputs are clean:

python -m http.server 8080
07 COMMIT

COMMIT YOUR CHANGES

STATION_07

Use conventional commit prefixes (feat:, fix:, docs:, style:):

git add . && git commit -m "feat(cli): add quick help command runner"
08 PUSH

PUSH BRANCH TO YOUR FORK

STATION_08

Push your feature branch to your GitHub origin:

git push origin feat/add-terminal-shortcut
09 MERGE

OPEN PR & LINK ISSUE

STATION_09

Open the Pull Request on the OSCC repository. In your PR description, write Closes #123 (or your issue number). A maintainer will review, provide feedback, and merge your code!
